# Lekcja 6.1 — Tablice

## Cel
Po lekcji uczeń:
- Tworzy tablicę dwoma sposobami i wie, ile ma elementów
- Rozumie, że indeksowanie zaczyna się od **zera**, a ostatni indeks to `Length - 1`
- Wie, że tablica ma **stały rozmiar** — i czemu to za chwilę zaboli
- Przechodzi po tablicy przez `for` i przez `foreach`
- Rozpoznaje `IndexOutOfRangeException`

> **To pierwszy raz, gdy jedna zmienna trzyma wiele wartości.** Uczeń pytał o to w lekcji 2.1 („a jak przechować sto imion?") i słyszał: „moduł 6".

## Krok 1 — Zakotwiczenie (5 min)

**Pytanie wejściowe:**
> „Kupujesz segregator z dwudziestoma ponumerowanymi przegródkami. Ile przegródek będzie miał za miesiąc?"

**Co chcesz usłyszeć:** dwadzieścia. Nie przybędzie ich samo.

**Drugie pytanie:**
> „Chcesz dołożyć dwudziestą pierwszą kartkę. Co robisz?"

**Co chcesz usłyszeć:** kupujesz większy segregator i przekładasz wszystko. **Zapamiętaj tę odpowiedź** — wraca w lekcji 6.2.

**Trzecie pytanie:**
> „Przegródki są ponumerowane. Od której liczby zaczyna się numeracja w twoim segregatorze?"

Uczeń powie „od jeden". Powiedz wtedy: „w C# zaczyna się od zera i to jest jedna z pierwszych rzeczy, które trzeba przestawić w głowie".

## Krok 2 — Mostek (10 min)

**Mostek:**
> „Segregator o ustalonej liczbie ponumerowanych przegródek, wszystkie na ten sam rodzaj zawartości — to w C# **tablica**."

Uczeń tworzy `kurs/zadania/14-tablice.cs`:

```csharp
string[] imiona = { "Ala", "Bo", "Cyd" };

Console.WriteLine(imiona[0]);
Console.WriteLine(imiona[1]);
Console.WriteLine(imiona[2]);
Console.WriteLine($"Liczba elementów: {imiona.Length}");
```
→ `Ala`, `Bo`, `Cyd`, `Liczba elementów: 3`

**Pytania:**
- „Co znaczy `[]` po `string`?" → „to nie jeden tekst, tylko tablica tekstów"
- „Jaki jest indeks pierwszego elementu? A ostatniego?" → `0` i `2`
- „Znasz już `Length` — skąd?" → z lekcji 5.3, gdzie liczyło znaki tekstu. Tu liczy elementy.

> **Ostatni indeks to `Length - 1`, nie `Length`.** To źródło większości pomyłek w tej lekcji. Przy trzech elementach numery to 0, 1, 2 — trójki nie ma.

Niech uczeń **spróbuje** `imiona[3]`:
```
Unhandled exception. System.IndexOutOfRangeException: Index was outside the bounds of the array.
```
> „Przeczytaj: »indeks był poza granicami tablicy«. To wyjątek w czasie działania, jak `FormatException` z lekcji 2.3 — program się zbudował i przewrócił w trakcie."

## Krok 3 — Eksperyment (25 min)

### A. Drugi sposób tworzenia — pusta tablica

```csharp
int[] oceny = new int[3];

Console.WriteLine($"{oceny[0]}, {oceny[1]}, {oceny[2]}");
Console.WriteLine(oceny.Length);
```
→ `0, 0, 0` i `3`

> „Nie wpisałeś żadnych liczb, a coś tam jest. Co?"
→ zera. **Tablica powstaje wypełniona wartościami domyślnymi** — `0` dla liczb, `false` dla `bool`.

> „Pamiętasz `CS0165` z lekcji 2.1, gdzie zwykła zmienna bez wartości nie dawała się odczytać? Tablica zachowuje się inaczej — element bez wartości ma zero."

To ważne rozróżnienie i uczeń trafi na nie ponownie w module 8.

### B. Zapisywanie do tablicy

```csharp
int[] oceny = new int[3];
oceny[0] = 5;
oceny[1] = 4;
oceny[2] = 3;

foreach (int ocena in oceny)
{
    Console.Write(ocena + " ");
}
Console.WriteLine();
```
→ `5 4 3`

> „`foreach` z lekcji 5.3 działa tu tak samo jak na tekście. Co się zmieniło?"
→ nic w składni. Zmienił się tylko rodzaj sekwencji.

**To jest zysk z kolejności lekcji:** `foreach` był już opanowany, więc tablica to jedyna nowa rzecz.

### C. `for` z indeksem — gdy numer jest potrzebny

```csharp
string[] imiona = { "Ala", "Bo", "Cyd" };

for (int i = 0; i < imiona.Length; i++)
{
    Console.WriteLine($"{i}: {imiona[i]}");
}
```
→ `0: Ala`, `1: Bo`, `2: Cyd`

> „Czemu warunek to `i < imiona.Length`, a nie `i <= imiona.Length`?"
→ bo ostatni indeks to `Length - 1`. `<=` dałoby `IndexOutOfRangeException`.

Niech uczeń **spróbuje** `<=` i zobaczy wyjątek. To ta sama pomyłka o jeden co w module 5, tylko z konsekwencją.

### D. Tablice **można** zmieniać

```csharp
string[] imiona = { "Ala", "Bo", "Cyd" };
imiona[1] = "Basia";
Console.WriteLine(string.Join(", ", imiona));
```
→ `Ala, Basia, Cyd`

> „`string.Join` skleja elementy przecinkiem — wygodne do wypisania całej tablicy jedną linią. Pierwszy argument to separator."

**Nie tłumacz `string.Join` głębiej.** To narzędzie, nie temat lekcji.

### E. Czego tablica **nie** potrafi

```csharp
int[] liczby = { 1, 2 };
liczby.Add(3);
```
→ `CS1061: 'int[]' does not contain a definition for 'Add'`

> „Chciałeś dołożyć element. Co odpowiedział kompilator?"
→ tablica nie ma czegoś takiego jak `Add`. **Rozmiar jest ustalony przy tworzeniu i nie da się go zmienić.**

To jest segregator z kroku 1: żeby dołożyć dwudziestą pierwszą kartkę, trzeba kupić nowy.

> „Więc co robisz, gdy nie wiesz z góry, ile elementów będziesz mieć?"

Odpowiedź to lekcja 6.2 — **i to jest cała jej motywacja.** Nie zdradzaj więcej niż nazwę: „`List`, następna lekcja".

### F. Suma i największy — wzorce, które wracają

```csharp
int[] oceny = { 5, 3, 4, 2, 5 };

int suma = 0;
foreach (int ocena in oceny)
{
    suma = suma + ocena;
}
Console.WriteLine($"Suma: {suma}, średnia: {(double)suma / oceny.Length:F2}");

int najwieksza = oceny[0];
foreach (int ocena in oceny)
{
    if (ocena > najwieksza)
    {
        najwieksza = ocena;
    }
}
Console.WriteLine($"Największa: {najwieksza}");
```
→ `Suma: 19, średnia: 3,80` i `Największa: 5`

> „Zwróć uwagę na `(double)suma` — bez tego wyszłoby dzielenie całkowite z lekcji 2.3."

> „A czemu `najwieksza` zaczyna od `oceny[0]`, a nie od zera?"
→ bo przy samych liczbach ujemnych zero byłoby złą odpowiedzią. **Zaczynaj od pierwszego elementu, nie od wymyślonej wartości.**

## Krok 4 — Pogłębienie (10 min)

**Indeks od końca — `^`**

```csharp
string[] imiona = { "Ala", "Bo", "Cyd" };
Console.WriteLine(imiona[imiona.Length - 1]);
Console.WriteLine(imiona[^1]);
```
→ obie linie dają `Cyd`

> „`^1` znaczy »pierwszy od końca«. Zwróć uwagę: od końca liczy się **od jedynki**, nie od zera."

**Zakres — `..`**

```csharp
Console.WriteLine(string.Join(",", imiona[0..2]));
```
→ `Ala,Bo`

> „`0..2` to »od zera włącznie do dwójki **bez** niej«. Ta sama logika co przy `i < Length`."

Oba zapisy są nowe (C# 8) i uczeń **nie musi ich używać** — ale zobaczy je w cudzym kodzie i lepiej, żeby rozpoznał.

**Tablica w pętli, której nie ma jak wypełnić:**
```csharp
int[] kwadraty = new int[5];
for (int i = 0; i < kwadraty.Length; i++)
{
    kwadraty[i] = i * i;
}
Console.WriteLine(string.Join(" ", kwadraty));
```
→ `0 1 4 9 16`

> „Tu `for` jest jedyną opcją. Czemu nie `foreach`?"
→ bo `foreach` nie daje indeksu, a indeks jest tu potrzebny **i** jako numer przegródki, **i** jako wartość do podniesienia do kwadratu.

## Krok 5 — Ćwiczenie

→ Skill `cwiczenie`. Temat: „tablice". Propozycje:

- 🔥 **Rozgrzewka** (`14-tablice-a.cs`): utwórz tablicę pięciu liczb wpisanych na stałe. Wypisz je wszystkie w jednej linii, a pod spodem — pierwszą i ostatnią, każdą z opisem.
- ⭐ **Główne** (`14-tablice-b.cs`): oceny. Utwórz tablicę na 5 ocen. W pętli zapytaj o każdą z osobna (`Ocena 1:`, `Ocena 2:`…), wczytując przez `TryParse` z powtarzaniem, aż uczeń poda liczbę. Na końcu wypisz: wszystkie oceny w jednej linii, sumę, średnią z dwoma miejscami po przecinku oraz najwyższą i najniższą.
- ⚡ **Gwiazdka** (`14-tablice-c.cs`): odwróć tablicę **bez** tworzenia drugiej. Utwórz tablicę siedmiu liczb, a potem zamień je miejscami w tej samej tablicy: pierwszy z ostatnim, drugi z przedostatnim i tak dalej. Wypisz przed i po. Podpowiedź: potrzebujesz zmiennej pomocniczej do zamiany dwóch wartości — i pętli, która idzie tylko do **połowy**.

Gwiazdka ma dwa haczyki: zamiana wartości wymaga trzeciej zmiennej, a pętla do końca odwróciłaby tablicę dwa razy, czyli wcale.

## Pułapki

- **Indeks od zera** — pierwszy element to `[0]`, ostatni `[Length - 1]`. Źródło większości błędów tej lekcji.
- **`i <= Length` w pętli** → `IndexOutOfRangeException`. Zawsze `<`.
- **Próba dołożenia elementu** → `CS1061`. Tablica ma stały rozmiar; do tego jest `List` (6.2).
- **Zapominanie, że tablica startuje wypełniona zerami** — pusta tablica `int[5]` nie jest „pusta", tylko pełna zer. Przy liczeniu średniej to zmienia wynik.
- **Szukanie największego od zera** — przy samych liczbach ujemnych da zły wynik. Zaczynaj od `tablica[0]`.
- **`Length` bez nawiasów** — to właściwość, nie metoda. `Length()` daje `CS1955: Non-invocable member 'Array.Length' cannot be used like a method.` (Dla porównania `List` ma `Count`, też bez nawiasów — patrz 6.2.)
- **`^1` mylone z `[-1]`** — w C# nie ma indeksów ujemnych; jest `^`.

## Aktualizacja 2026 (z `AKTUALIZACJE.md`)

Sekcja `[moduł 6]`. Dwie rzeczy, których w starszych materiałach nie ma:

- **Indeks od końca `^1`** i **zakresy `..`** to C# 8. Wcześniej pisało się `tablica[tablica.Length - 1]` i kopiowało fragmenty pętlą. Obie stare formy nadal działają i uczeń zobaczy je częściej.
- **`ArrayList`** ze starych poradników to poprzednik `List<T>`, który nie pilnował typu. Jeśli uczeń go przyniesie: „to sprzed dwudziestu lat, dziś jest `List<T>`, poznasz w następnej lekcji".

## Notatki tutora

- **Krok 3.E jest zaplanowaną frustracją.** Uczeń ma spróbować `Add` i dostać błąd — to jedyna motywacja do lekcji 6.2, która naprawdę działa. Nie uprzedzaj, że się nie da.
- **Nie wprowadzaj `List`.** Nazwa i numer lekcji, nic więcej.
- **Nie tłumacz, czemu indeksowanie zaczyna się od zera.** Powody są historyczne i techniczne; uczniowi wystarcza „tak jest i trzeba się przyzwyczaić". Rozwijanie tego zabiera pięć minut i niczego nie daje.
- **`string.Join` pokazuj jako narzędzie.** Uczeń będzie go używał do końca kursu; wyjaśnienie jednym zdaniem wystarcza.
- **`^1` i `..` to materiał rozpoznawczy**, nie warsztatowy. Jeśli uczeń zacznie ich używać — w porządku, ale nie wymagaj.
- Uczeń, który w module 5 opanował `foreach`, wejdzie w tablice bardzo szybko. Jeśli tak jest — nie rozciągaj lekcji; przejdź do ćwiczeń wcześniej.
