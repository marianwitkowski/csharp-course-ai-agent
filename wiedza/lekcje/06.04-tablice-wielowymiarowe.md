# Lekcja 6.4 — Tablice wielowymiarowe

## Cel
Po lekcji uczeń:
- Tworzy tablicę dwuwymiarową `int[,]` i sięga do niej dwoma indeksami
- Przechodzi po niej dwiema zagnieżdżonymi pętlami
- Zna `GetLength(0)` i `GetLength(1)` i wie, czym różnią się od `Length`
- Rozróżnia tablicę prostokątną `[,]` od tablicy tablic `[][]`
- Wie, kiedy która jest właściwa

> **To ostatnia lekcja modułu 6** i jedyna, której uczeń może nie potrzebować przez długi czas. Powiedz mu to wprost: „poznajesz to, żeby rozpoznać; użyjesz, gdy trafisz na planszę, tabelę albo siatkę".

## Krok 1 — Zakotwiczenie (5 min)

**Pytanie wejściowe:**
> „Plansza do gry w kółko i krzyżyk. Jak opiszesz komuś przez telefon, gdzie postawiłeś krzyżyk?"

**Co chcesz usłyszeć:** dwie liczby — wiersz i kolumna. Albo „środkowe pole", ale dopytaj o sposób ogólny.

**Drugie pytanie:**
> „Ile liczb potrzebujesz, żeby wskazać jedno pole? A ile na liście zakupów z poprzedniej lekcji?"

**Co chcesz usłyszeć:** tutaj dwie, tam jedna. **To jest cała różnica** — nie nazywaj jej jeszcze.

**Trzecie pytanie:**
> „A gdyby to nie była plansza, tylko lista klas w szkole, gdzie w każdej klasie jest inna liczba uczniów?"

**Co chcesz usłyszeć:** wiersze różnej długości. Zapamiętaj — to jest różnica między dwoma rodzajami tablic w kroku 4.

## Krok 2 — Mostek (10 min)

**Mostek:**
> „Tablica z lekcji 6.1 miała jeden rząd przegródek. Teraz potrzebujesz siatki — wierszy i kolumn. W C# zapisuje się to przecinkiem w nawiasach kwadratowych: `int[,]`."

Uczeń tworzy `kurs/zadania/17-wielowymiarowe.cs`:

```csharp
int[,] plansza = new int[2, 3];

plansza[0, 0] = 1;
plansza[1, 2] = 9;

Console.WriteLine(plansza[0, 0]);
Console.WriteLine(plansza[1, 2]);
Console.WriteLine(plansza[0, 1]);
```
→ `1`, `9`, `0`

**Pytania:**
- „Co znaczy `[2, 3]` przy tworzeniu?" → dwa wiersze, trzy kolumny
- „Czemu `plansza[0, 1]` daje zero, choć nic tam nie wpisałeś?" → **wartości domyślne**, jak w lekcji 6.1
- „Ile jest wszystkich pól?" → sześć

> **Pierwsza liczba to wiersz, druga to kolumna** — i obie liczą się od zera, tak jak w 6.1. Przy `new int[2, 3]` prawidłowe wiersze to 0 i 1, kolumny 0, 1 i 2.

## Krok 3 — Eksperyment (20 min)

### A. `Length` kontra `GetLength`

```csharp
int[,] plansza = new int[2, 3];

Console.WriteLine(plansza.Length);
Console.WriteLine(plansza.GetLength(0));
Console.WriteLine(plansza.GetLength(1));
```
→ `6`, `2`, `3`

> „`Length` dało sześć. Czego się spodziewałeś?"

`Length` liczy **wszystkie pola razem**. Do wymiarów służy `GetLength`: `GetLength(0)` to liczba wierszy, `GetLength(1)` — kolumn.

> „Zwróć uwagę: `GetLength` **ma nawiasy**, bo to metoda, a `Length` ich nie ma, bo to właściwość. Pamiętasz `CS1955` z lekcji 6.1?"

### B. Przejście dwiema pętlami

```csharp
int[,] plansza = new int[2, 3];
plansza[0, 0] = 1;
plansza[1, 2] = 9;

for (int wiersz = 0; wiersz < plansza.GetLength(0); wiersz++)
{
    for (int kolumna = 0; kolumna < plansza.GetLength(1); kolumna++)
    {
        Console.Write(plansza[wiersz, kolumna] + " ");
    }
    Console.WriteLine();
}
```
→
```
1 0 0 
0 0 9 
```

> „To jest zagnieżdżona pętla z lekcji 5.2, tylko teraz ma po co być. Gdzie w tym kodzie kończy się wiersz?"
→ przy `Console.WriteLine()` po wewnętrznej pętli. Bez niego wszystko wypisałoby się w jednej linii.

Niech uczeń **usunie** tę linię i zobaczy różnicę.

> **Użycie `GetLength` zamiast wpisanych liczb 2 i 3 jest tu ważne.** Gdy zmienisz rozmiar tablicy w jednym miejscu, pętle dostosują się same.

### C. Wypełnianie tabliczką mnożenia

```csharp
int[,] tabliczka = new int[5, 5];

for (int w = 0; w < tabliczka.GetLength(0); w++)
{
    for (int k = 0; k < tabliczka.GetLength(1); k++)
    {
        tabliczka[w, k] = (w + 1) * (k + 1);
    }
}

for (int w = 0; w < tabliczka.GetLength(0); w++)
{
    for (int k = 0; k < tabliczka.GetLength(1); k++)
    {
        Console.Write($"{tabliczka[w, k],4}");
    }
    Console.WriteLine();
}
```

> „`{...,4}` w interpolacji wyrównuje do czterech znaków. Przecinek po nazwie zmiennej, przed dwukropkiem formatu z lekcji 3.1."

**To nowe narzędzie — jedno zdanie i dalej.** Bez wyrównania tabliczka się rozjedzie i uczeń sam to zobaczy, jeśli spróbuje bez.

### D. `foreach` po tablicy dwuwymiarowej

```csharp
int suma = 0;
foreach (int pole in tabliczka)
{
    suma = suma + pole;
}
Console.WriteLine($"Suma wszystkich pól: {suma}");
```

> „`foreach` działa, ale czego nie wiesz w środku tej pętli?"
→ **w którym wierszu i kolumnie jesteś.** `foreach` przechodzi po wszystkich polach po kolei, ale nie mówi gdzie.

Ta sama zasada co w 5.3: `foreach` gdy pozycja nieważna, `for` gdy ważna.

## Krok 4 — Pogłębienie (10 min)

**Dwa różne rodzaje — prostokątna i postrzępiona**

Tablica prostokątna `[,]` ma **każdy wiersz tej samej długości**:
```csharp
int[,] prostokatna = new int[2, 3];   // zawsze 2 × 3
```

Tablica tablic `[][]` to tablica, której **elementami są tablice** — każda może mieć inną długość:
```csharp
int[][] postrzepiona = new int[2][];
postrzepiona[0] = new int[] { 1, 2 };
postrzepiona[1] = new int[] { 3, 4, 5 };

Console.WriteLine(postrzepiona[0].Length);
Console.WriteLine(postrzepiona[1].Length);
Console.WriteLine(postrzepiona[1][2]);
```
→ `2`, `3`, `5`

> „Zauważ zapis dostępu: `postrzepiona[1][2]` — dwa osobne nawiasy, nie przecinek. Bo to naprawdę tablica **w** tablicy."

To jest szkoła z kroku 1, gdzie każda klasa ma inną liczbę uczniów.

| Rodzaj | Zapis | Dostęp | Kiedy |
| --- | --- | --- | --- |
| prostokątna | `int[,]` | `t[w, k]` | plansza, tabela, siatka |
| postrzępiona | `int[][]` | `t[w][k]` | wiersze różnej długości |

> „W tym kursie wystarczy ci prostokątna. Postrzępioną pokazuję, żebyś rozpoznał zapis z dwoma nawiasami, gdy go zobaczysz."

**Trzy wymiary i więcej**
```csharp
int[,,] szescian = new int[2, 2, 2];
```
> „Da się. Praktycznie nigdy nie jest potrzebne poza grafiką i obliczeniami naukowymi. Wspominam dla porządku."

**Lista list zamiast tablicy dwuwymiarowej**

Z lekcji 6.2 uczeń zna `List<List<string>>`. Warto zestawić:

| Potrzeba | Wybór |
| --- | --- |
| siatka o stałym rozmiarze | `int[,]` |
| wiersze dokładane w trakcie | `List<List<T>>` |

> „Tablica dwuwymiarowa ma stały rozmiar — tak jak zwykła tablica z 6.1. Jeśli wierszy ma przybywać, potrzebujesz listy."

## Krok 5 — Ćwiczenie

→ Skill `cwiczenie`. Temat: „tablice wielowymiarowe". Propozycje:

- 🔥 **Rozgrzewka** (`17-wielowymiarowe-a.cs`): utwórz tablicę 3 × 3 wypełnioną zerami. Wpisz jedynki na przekątnej (`[0,0]`, `[1,1]`, `[2,2]`) i wypisz całość jako siatkę.
- ⭐ **Główne** (`17-wielowymiarowe-b.cs`): oceny w tabeli. Utwórz tablicę 3 × 4 (trzej uczniowie, po cztery oceny) i wypełnij ją w pętli liczbami wczytanymi od użytkownika (`Uczeń 1, ocena 1:` i tak dalej), przez `TryParse` z powtarzaniem. Wypisz tabelę, a obok każdego wiersza — średnią tego ucznia z dwoma miejscami po przecinku.
- ⚡ **Gwiazdka** (`17-wielowymiarowe-c.cs`): kółko i krzyżyk — sprawdzarka. Utwórz planszę 3 × 3 jako `char[,]` wypełnioną znakami `'.'`, wstaw kilka `'X'` i `'O'` na stałe, wypisz planszę. Potem sprawdź, czy któryś **wiersz** składa się z trzech takich samych znaków innych niż `'.'` — i wypisz który. (Kolumny i przekątne możesz dołożyć, jeśli chcesz; wiersze wystarczą na zaliczenie.)

Gwiazdka wymaga pętli po wierszach z porównaniem trzech pól naraz — czyli `&&` z lekcji 4.2 w środku zagnieżdżenia.

## Pułapki

- **`Length` zamiast `GetLength`** — `Length` na tablicy 2 × 3 daje 6, nie 2. Do wymiarów służy `GetLength(numer)`.
- **Zamiana wiersza z kolumną** — `[w, k]` czy `[k, w]`? Przy tablicy kwadratowej program działa i wynik jest cicho przestawiony. Sprawdzaj na tablicy **prostokątnej**, nie kwadratowej.
- **Przecinek kontra dwa nawiasy** — `t[1, 2]` dla prostokątnej, `t[1][2]` dla postrzępionej. Pomylenie daje błąd kompilacji.
- **Brak `Console.WriteLine()` po wewnętrznej pętli** — wszystko wypisuje się w jednej linii.
- **Wpisane na sztywno rozmiary w pętlach** — po zmianie rozmiaru tablicy pętle przestają pasować. Zawsze `GetLength`.
- **Tworzenie postrzępionej bez wypełnienia wierszy** — `new int[2][]` daje dwa **puste miejsca**; próba `t[0][0]` bez wcześniejszego `t[0] = new int[3]` daje `NullReferenceException` — wiersza po prostu jeszcze nie ma.
- **Indeksy od zera w obu wymiarach** — przy `new int[3, 3]` nie ma ani wiersza 3, ani kolumny 3.

## Notatki tutora

- **Powiedz uczniowi wprost, że ta lekcja jest „na zapas".** Tablice dwuwymiarowe są rzadziej potrzebne niż listy i słowniki; szczerość co do tego buduje zaufanie i zdejmuje presję.
- **Krok 3.B używa zagnieżdżonej pętli z lekcji 5.2** — tam wyglądała na sztuczkę bez zastosowania, tutaj ma powód. Warto to nazwać.
- **Nie rozwijaj tablic postrzępionych.** Rozpoznanie zapisu `[][]` wystarczy; kurs ich nie używa.
- **Nie wprowadzaj `GetUpperBound`** ani `Rank`. `GetLength` wystarcza.
- **Wyrównanie `{x,4}` w interpolacji** to nowe narzędzie — jedno zdanie. Jeśli uczeń chce ładniejszych tabel, to jest właściwe miejsce, ale nie temat lekcji.
- **Pułapkę z zamianą wiersza i kolumny sprawdza się na tablicy prostokątnej.** Jeśli uczeń ćwiczy na 3 × 3, błąd się nie ujawni — zaproponuj 2 × 4.
- **Moduł 6 się kończy.** Warto podsumować cztery lekcje jednym pytaniem: „po czym będziesz szukać — po numerze czy po nazwie?" — i dopiero potem, czy liczba elementów jest stała.
